# avero-it Homebrew tap

Homebrew casks for [sie](https://github.com/avero-it/sie), the siMPLE eDITOR: a modeless terminal text editor.

```sh
brew install --cask avero-it/tap/sie
```

Works on macOS and Linux (amd64 and arm64). The cask is updated automatically by each sie release; don't edit it by hand.
